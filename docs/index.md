# lmfit-global

**lmfit-global** is a flexible and extensible framework for performing **global (single-run) curve fitting** across **multiple datasets** and  **multiple model components** using [`lmfit`](https://lmfit.github.io/lmfit-py/).

It is designed for scientific workflows where parameters must be
**shared, constrained, or jointly optimized** across datasets.

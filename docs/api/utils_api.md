# Utilities API

The `utils` subpackage provides shared infrastructure used throughout
**lmfit-global**.  
These utilities are intentionally decoupled from the core fitting logic
and are safe to reuse independently.

They cover:

- Logging and configuration helpers
- Parameter normalization and validation
- Reporting and formatting utilities
- I/O helpers (exporting data, parameters, results)
- Plotting helpers
- Centralized dependency handling
